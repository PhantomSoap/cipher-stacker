#Cipher Stacker

A Rust based Ciphering app using the technique of cipher stacking where multipleciphers are 'stacked' on top of the plaintext.

##Ratzilla Web app 

Available at https://phantomsoap.github.io/cipher-stacker/

##Tui App 

run with cargo run --bin cipher-stacker-tui

##Build

Ratzilla App (Requires trunk) - trunk build
Ratatui tui - cargo build --bin cipher-stacker-tui
